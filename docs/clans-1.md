# Clans 1.0

Социальные стаи поверх существующего clan foundation. Не Clan Wars. Не pay-to-win.

Геймплей кланов — только в DM. Group chat не публикует хаб, вклад, задания и состав.

## Unlock

Канонический gate: флаг `week_1_complete`.

До этого хаб отвечает: «Кланы откроются после первой печати.» Команды `CLAN_ACT` отклоняются.

Игрок состоит только в одном клане (`clan_members.player_id` unique).

## Хаб

Без клана (5 кнопок):

- 🔎 Найти клан
- ➕ Создать клан
- 📩 Заявки
- 🏆 Рейтинг
- ⬅ Назад

В клане:

- 🏕 Мой клан
- 🎯 Задания
- 📦 Вклад
- 🏆 Рейтинг
- ⬅ Назад

## Создание

- название 3–24, tag 2–5, unique case-insensitive (`name_key` / `tag_key`)
- запрет control/URL/HTML/JSON-like и резервных имён (`admin`, `system`, `kubolesie`, …)
- стоимость: **200 монет** (не premium). После Week 1 500 слишком дорого для типичного запаса
- создатель получает роль `LEADER` (существующий enum, не OWNER)

## Роли

| Роль | Права |
| --- | --- |
| LEADER | всё: офицеры, передача, описание, kick officer/member, роспуск |
| OFFICER | заявки, kick только MEMBER |
| MEMBER | просмотр, вклад, задания, выход |

Роль читается только из БД. Payload `role` игнорируется.

## Заявки

Одна активная заявка на игрока. Unique partial index `clan_applications_one_pending_per_player`.

Принять / отклонить — officer+. Если кандидат уже в другом клане — заявка закрывается, join не проходит. Member cap проверяется в транзакции (`SELECT … FOR UPDATE`).

## Вклад

Принимаются: `LOG=1`, `COBBLESTONE=1`, `HIDE=2`, `IRON_INGOT=4`, `MIST_RESIN=5`, `BOG_CORE=15`.

Seal shards и прочий сюжетный лут не принимаются. Списание атомарное, без отрицательного баланса. Duplicate `event_id` не списывает повторно.

## Уровень 1–10

По cumulative `clans.xp` (очки клана):

`0 / 500 / 1500 / 3500 / 7000 / 12000 / 20000 / 32000 / 50000 / 75000`

Реальный бонус уровня — member cap: `10 + 2×(level-1)`, на 10 уровне **30**.

Боевых бонусов нет.

## Задания

Детерминированный пул по UTC day/week key. Без cron-строк на каждый клан.

Daily (2 из пула): 100 брёвен / 20 PvE / 10 PvP / 15 крафт.

Weekly (1 из пула): 5 боссов / 500 вклада / 50 PvP / 100 PvE.

Прогресс идёт от реальных gameplay events (`noteActivity`). Награда игроку — только если он участвовал в этом периоде. Claim once: `reward_claims (clan_task, clanId:period:taskId)`.

Клан при закрытии задания получает score: daily 40 / weekly 200.

## Рейтинг

Top 10 по **недельному** вкладу (`period_key = ISO week`), не lifetime.

Tie-break: weekly score → clan level → `created_at` → id.

## Выход / передача / роспуск

- MEMBER/OFFICER может выйти
- LEADER с другими участниками не выходит: передаёт лидерство или распускает
- передача: старый лидер становится OFFICER
- роспуск: два шага, токен в player flags, нельзя подделать
- после disband: memberships сняты, заявки закрыты, история contribution/score остаётся (soft-delete `disbanded_at`)
- ресурсы игрокам не возвращаются

## PvP

Обычные PvP матчи участников считаются в клановые задания. Clan Wars / осады / потеря ресурсов — не в этом релизе.

## Аналитика

`GET /v1/admin/analytics/clans` — агрегаты без массовых VK ID.
