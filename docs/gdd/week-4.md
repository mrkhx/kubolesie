# Куболесье | Чат-RPG — GDD Week 4 (Days 22–28)

**Статус:** канон реализации Prototype 0.0.10.  
**Тема:** «Четвёртая печать — Гнилая тропа».  
**Назначение:** сюжетная глава после Week 3. Не копия босс-недели. Не Week 5.

Недели 1–3 **не отменяются**. Сохранения с `week_3_complete` начинают День 22. Решения Week 1–3 читаются как реплики и бонусы, не как отдельные кампании. Новых больших систем нет: Jobs, Production, Market, Clan, PvP — только optional слой.

## 0. Принципы

- Чат: 2–5 кнопок. VK — только интерфейс. Логика в Game Core. PostgreSQL — SoT.
- Combat engine не переписывается. Модификаторы — снимок + seed.
- Нет платежей, Mini App, clan wars, clan boss, workers, premium combat boosts, buy orders, нового tool tier, cron.
- Названия только «Куболесье».
- Soft-lock запрещён. Поражение не уничтожает инвентарь.
- Ни один бонус (профессия, двор, рынок, клан, PvP, питомец, фонарь, лук, щит) не обязателен.
- Главная мысль недели: печати не просто ломаются. Кто-то меняет путь к ним. Антагониста, создателей и причину не называть.

## 8. Системы

- Jobs: реальный gather/craft/PvE двигает существующие контракты. Production collect — нет.
- Production: FOOD/LOG/COBBLE/COAL как запас. Новых дворов нет.
- Market: ROT_RESIN в allowlist. Ядра и осколки — deny. Без buy orders и system listings.
- Clan: flavour + скидка пайка при show. Не gate, не war, не clan boss.
- PvP: optional социальная ветка. Без потери вещей и без отдельного рейтинга Week 4.
- Герой после week1: Профиль / PvP / Рынок / Клан / Назад.
