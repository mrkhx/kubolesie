# Куболесье | Чат-RPG — GDD Week 5 (Days 29–35)

**Статус:** канон реализации Prototype 0.0.11.  
**Тема:** «Пятая печать — Чёрная топь».  
**Назначение:** сюжетная глава после Week 4. Не копия босс-недели. Не Week 6.

Недели 1–4 **не отменяются**. Сохранения с `week_4_complete` начинают День 29. Решения Week 1–4 читаются как реплики и бонусы, не как отдельные кампании. Новых больших систем нет: Jobs, Production, Market, Clan, PvP — только optional слой.

---

## 0. Принципы

- Чат: 2–5 кнопок. VK — только интерфейс. Логика в Game Core. PostgreSQL — SoT.
- Combat engine не переписывается. Модификаторы — снимок + seed.
- Нет платежей, Mini App, clan wars, clan boss, workers, premium combat boosts, buy orders, нового tool tier, cron.
- Названия только «Куболесье».
- Soft-lock запрещён. Поражение не уничтожает инвентарь.
- Ни один бонус (профессия, двор, рынок, клан, PvP, питомец, фонарь, лук, щит) не обязателен.
- Главная мысль недели: вмешательство в сеть происходит **прямо сейчас**. Не древний след. Не старая правка. Свежая. Тот, кто меняет сеть, ещё здесь. Личность, создатель сети и финал не называются.

## 8. Системы

- Jobs: реальный gather/craft/PvE двигает существующие контракты. Production collect — нет. FISHER — extra flavour на камышовой переправе, не gate.
- Production: FOOD/LOG/COBBLE/COAL/FISH как запас. Нового двора BLACK_REED нет.
- Market: BLACK_REED в allowlist. Сердце и осколок — deny. Без buy orders и system listings.
- Clan: flavour + скидка пайка при show. Не gate, не war, не clan boss.
- PvP: optional социальная ветка. Без потери вещей и без отдельного рейтинга Week 5.
- Герой после week1: Профиль / PvP / Рынок / Клан / Назад.
